# Design: Migrate Go REST API Template to Fiber v3

**Date:** 2026-08-08
**Status:** Approved

## Purpose

Rewrite the existing Go REST API template (currently Gin-based) using **Fiber v3**,
the current major release. Motivation: smaller dependency footprint (Gin pulls
`sonic`, `quic-go`, and `mongo-driver` trees — ~60% of module weight), a faster
router, and the user's preference for Fiber. Swagger UI is preserved at
`/swagger` via `gofiber/contrib/v3/swaggerui`.

The database is an empty Neon Postgres, so `AutoMigrate` can recreate tables from
scratch with no migration concerns.

## Tech Stack

- **HTTP:** Fiber v3 (`github.com/gofiber/fiber/v3`) — handlers take `fiber.Ctx` interface (not pointer).
- **API docs:** Swag CLI v1 (`swag init` generates `docs/`) + `github.com/gofiber/contrib/v3/swaggerui` serving `docs/swagger.json`.
- **Validation:** `github.com/go-playground/validator/v10` wired via `fiber.Config{StructValidator: ...}`; DTO tags switch from `binding:` to `validate:`.
- **Database access:** GORM (Postgres driver) — unchanged.
- **Auth:** golang-jwt/v5 — unchanged.
- **Password hashing:** `golang.org/x/crypto/bcrypt` — unchanged.
- **Config:** `.env` via `godotenv` — unchanged.

## Dependency Changes

Remove (transitive Gin tree):
- `github.com/gin-gonic/gin`
- `github.com/swaggo/gin-swagger`
- `github.com/swaggo/files`
- `GIN_MODE` config key

Add:
- `github.com/gofiber/fiber/v3`
- `github.com/gofiber/contrib/v3/swaggerui`
- `github.com/go-playground/validator/v10`

Keep:
- `gorm.io/gorm`, `gorm.io/driver/postgres`
- `github.com/glebarez/sqlite` (test-only, in-memory)
- `github.com/golang-jwt/jwt/v5`
- `github.com/joho/godotenv`
- `golang.org/x/crypto`

## Project Layout

Unchanged from the Gin design except framework-specific files are rewritten:

```
go-backend/
├── main.go                  # Fiber wiring: config, DB, migrate, router, swaggerui
├── docs/                    # generated by `swag init`
├── pkg/
│   ├── config/config.go     # AppEnv replaces GinMode
│   ├── database/db.go       # unchanged
│   ├── middleware/
│   │   ├── auth.go          # rewritten for fiber.Ctx
│   │   └── cors.go          # rewritten for fiber.Ctx
│   └── token/token.go       # unchanged
└── internal/
    ├── models/              # unchanged
    ├── dto/                 # binding: -> validate: tags
    ├── handlers/            # rewritten: fiber.Ctx, Bind().Body, Status().JSON
    ├── services/            # unchanged
    └── router/router.go     # rewritten: fiber.New, groups, swaggerui mount
```

## Rewritten Layers (Fiber v3 specifics)

**`pkg/config`** — replace `GinMode string` with `AppEnv string` (read from
`APP_ENV`, default `development`). No Fiber equivalent of `GIN_MODE` is needed.

**`pkg/middleware/auth.go`**
- `RequireAuth(db, secret) fiber.Handler`: read `c.Get("Authorization")`, require
  `Bearer ` prefix, `token.Parse`, load user, store via `c.Locals(userKey, &user)`, `c.Next()`.
- `RequireRole(role) fiber.Handler`: check `CurrentUser(c).Role`, else 403.
- `CurrentUser(c fiber.Ctx) *models.User` via `c.Locals(userKey)`.

**`pkg/middleware/cors.go`** — `CORS() fiber.Handler`: set allow headers on
`c.Response()`, short-circuit `OPTIONS` with 204, `c.Next()`.

**`internal/dto`** — tag migration only: `binding:"required,email"` →
`validate:"required,email"`, `binding:"required"` → `validate:"required"`.

**`internal/handlers`**
- Signatures: `func (h *AuthHandler) Register(c fiber.Ctx) error`.
- Bind: `c.Bind().Body(&req)` (returns validation error).
- Respond: `c.Status(http.StatusCreated).JSON(...)`; errors via
  `respondError(c fiber.Ctx, status int, message string)`.
- Path params: `fiber.Params[int](c, "id", 0)`.
- Status-only: `c.SendStatus(http.StatusNoContent)`.
- Swag `@` annotations unchanged; all endpoints keep same routes and schemas.

**`internal/router`** — `fiber.New(fiber.Config{StructValidator: ...})`, register
`/healthz`, group `/api/v1`, protected group with `RequireAuth`, admin subgroup
`/users` with `RequireRole(models.RoleAdmin)`. Mount swaggerui at `/swagger`.

**`main.go`** — load env + config, `database.Connect`, `AutoMigrate`,
`router.New(db, cfg)`, `app.Listen(":" + cfg.Port)`. Keep top-level swag
annotations (`@title`, `@securityDefinitions.apikey BearerAuth`, etc.).

## Unchanged Layers

- `internal/models` (User, Todo, roles).
- `internal/services` (auth, todo, user + errors) — no Gin dependency.
- `pkg/database` — unchanged.
- `pkg/token` — unchanged.

## Swagger

- `swag init` (CLI v1) regenerates `docs/`; no runtime swag dependency needed by
  swaggerui.
- `swaggerui.New(swaggerui.Config{BasePath: "/", FilePath: "./docs/swagger.json",
  Path: "swagger", Title: "Go REST API Template API"})`.
- UI at `/swagger` (swaggerui index). Security definition `BearerAuth` preserved
  via top-level main.go annotations so protected endpoints keep the lock icon.

## Endpoints

Identical to the Gin design (public + auth + admin routes), same request/response
shapes. See previous spec for the full list.

## Testing

- `go test ./... -race` remains the final gate.
- Rewrite middleware and handler tests to use Fiber's `app.Test(req)` (returns
  `*http.Response`) + in-memory sqlite.
- Service and token tests stay unchanged (framework-agnostic).
- Live smoke check: boot against Neon, `/healthz` 200, `/swagger` 200, register
  returns user.

## Configuration (.env)

- `PORT` (default `8080`)
- `POSTGRESQL_DATABASE` (Neon URL)
- `JWT_SECRET`
- `TOKEN_HOURS` (default 24)
- `APP_ENV` (default `development`) — replaces `GIN_MODE`

## Out of Scope

- No changes to auth semantics, endpoints, or data model (pure framework swap).
- No benchmark harness (user only asked for the swap).
- Fiber stays the only HTTP framework; no Gin fallback retained.
